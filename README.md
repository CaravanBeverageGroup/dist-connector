# dist-connector

> **ПУБЛИЧНЫЙ РЕПОЗИТОРИЙ.** Нельзя коммитить `.env`, пароли, токены, ключи, сертификаты, IP-адреса и названия внутренних серверов. Допускается только `.env.example` с заглушками.

Клиентский сервис автоматической выгрузки (коннектор обмена данными) для развертывания в Docker на виртуальной машине дистрибьютора:
- Работает строго в режиме **Read-Only** к локальной СУБД 1С дистрибьютора.
- Получает с центрального сервера CBG подписанный манифест (SQL, окно, расписание) и **проверяет подпись** перед выполнением.
- Выполняет только одиночный `SELECT`, фильтрует данные строго по ассортименту CBG внутри сети партнера.
- Пишет полный текст выполняемого SQL в локальный лог на этой машине, чтобы ИТ партнера мог его проверить.
- Отправляет сжатый батч по защищенному HTTPS-каналу (только исходящие соединения).

## Запуск
Настройка — по `.env.example` (реальные значения хранятся только в `.env` на VM). Запуск выполняется по таймеру хоста (см. `deploy/`).

## Структура
- `src/` — код коннектора.
- `keys/` — публичные ключи проверки подписи.
- `deploy/` — compose, systemd unit/timer, скрипт тика.
- `scripts/` — служебные проверки.
